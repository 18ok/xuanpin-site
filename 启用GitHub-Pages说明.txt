玄品心决 · GitHub Pages 部署说明

仓库（公开）: https://github.com/18ok/xuanpin-site
站点 URL: https://18ok.github.io/xuanpin-site/

在 GitHub 仓库 Settings → Pages 中，将 Build and deployment 的 Source 设为 GitHub Actions。

推送 master/main 分支后，.github/workflows/pages.yml 会自动构建并发布静态站。

本地预览：双击「本地预览-仅开发用.bat」，勿直接双击 index.html（阅读全文需 HTTP 服务）。
